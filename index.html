Daten auf diesem Gerät

Alles bleibt auf diesem Gerät. Jeder Trainer hat seine eigenen Daten. Weitergeben geht über „Einheit teilen“ oder eine Sicherung.

Umzug von den alten Adressen

Du hast Planung, Zirkel oder die Trainer-App schon unter einer anderen Adresse benutzt? So kommen deine Daten hierher:

  1. Die alte App auf diesem Gerät öffnen, so wie bisher über das Symbol auf dem Home-Bildschirm.
  2. Oben auf „Daten mitnehmen und wechseln“ tippen. Die Daten werden automatisch übertragen.
  3. Diese Seite über Teilen → Zum Home-Bildschirm neu ablegen. Das alte Symbol kannst du danach löschen.

Alternativ: In der alten App unter „Daten“ eine Sicherung speichern und hier mit „Sicherung laden“ einlesen. Spotify muss an der neuen Adresse einmal neu verbunden werden.
